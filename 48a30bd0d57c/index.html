核心参数详解与场景选型

通用核心参数解析

两个工具底层均基于 Tencent ncnn 推理框架，参数定义高度一致：

参数与说明 常见取值 作用与配置建议
-n
waifu2x: Denoise（降噪等级）		 -1 / 0 / 1 / 2 / 3 降噪强度控制：
• -1：纯放大不降噪（高清原图、矢量线稿推荐）
• 0：极轻微去噪
• 1：日常首选，轻度消除模糊杂讯，线条清晰锐利
• 2 ~ 3：强力涂抹，专治高压缩、严重马赛克的 JPEG 旧图
-n
Real-ESRGAN: Model（模型名称）		 realesr-animevideov3
realesrgan-x4plus		 参数复用为指定模型：
• realesr-animevideov3：二次元动漫首选，色彩不失真
• realesrgan-x4plus：真实摄影 / 3D 渲染，补充微观细节
-s
两者通用：Scale（放大倍数）		 整数倍率 分辨率长宽缩放系数与模型约束：
• waifu2x 支持 1 / 2 / 4 / 8 / 16 / 32（默认 2）
• realesr-animevideov3 仅支持 2 / 3 / 4 倍（默认 4）
• realesrgan-x4plus 仅支持 4 倍
-f
两者通用：Format（输出格式）		 png / jpg / webp 图像编码容器：
• png（首选）：无损保存，防止放大后二次压缩劣化
• webp：体积更小，兼顾质量，适合超大壁纸长期存储
-g
两者通用：GPU ID（设备索引）		 0 / 1 / ... 运行设备指定：
双显卡机器必须显式指定独显（通常为 1，可在日志确认）；误走核显会导致处理速度降低数倍
-t
两者通用：Tile Size（切片大小）		 0 / 100 / 200 / 400 显存切片分块粒度：
• 默认 0 自动计算；显存充裕建议设为 200 或 400
• 处理超大图显存溢出（Vulkan OOM）时，缩减至 100
-m
两者通用：Model Path（权重路径）		 目录绝对路径 模型文件查找目录：
二进制默认按当前工作目录寻址，务必传绝对路径（如 ~/.local/opt/.../models），避免切换目录执行时报错闪退

场景与模型选型矩阵

场景 推荐引擎 推荐模型/核心参数 核心特性
二次元插画 / 赛璐珞动漫 waifu2x -m models-cunet -s 2 -n 1 线条锐利干净，不生造杂质纹理，对 2D 平面效果极佳。
动漫重度压缩噪点修复 waifu2x -m models-cunet -n 2 强力消除网络图多次转压产生的振铃效应与 JPEG 杂色块。
写实照片 / 3D 渲染 Real-ESRGAN -n realesrgan-x4plus -s 4 针对现实纹理（发丝、布料、皮肤肌理）自动补充微观细节。
复杂场景动漫壁纸 4X 放大 Real-ESRGAN -n realesr-animevideov3 -s 4 专为动漫微调的轻量模型，色彩保持度高且线条不易产生畸变。
